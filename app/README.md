# روزنما ✨ — برنامه‌ریز زندگی، ردیاب رشد و حالت تمرکز

اپ **تک‌کاربره، خصوصی و کاملاً آفلاین** برای برنامه‌ریزی روزانه بر پایه‌ی «روزشمار ۲.۰»:
برنامه‌ی هر روز از روی قالب‌های هفتگی و **اوقات شرعی محاسباتی** ساخته می‌شود (بدون اینترنت)،
کارها را تیک می‌زنی و نمودار رشد خودش جلو می‌رود.

## چرا PWA؟ (بنچمارک فریم‌ورک)

| گزینه | حجم نصب | اندروید | دسکتاپ | آفلاین | نتیجه |
|---|---|---|---|---|---|
| Flutter | ۲۰–۴۰ مگابایت APK | ✅ | با بیلد جدا | ✅ | سنگین برای نیاز ما |
| React Native | ۲۵–۵۰ مگابایت | ✅ | ❌ | ✅ | بدون نسخه‌ی دسکتاپ |
| Electron | ۸۰+ مگابایت | ❌ | ✅ | ✅ | فقط دسکتاپ و سنگین |
| **PWA (این اپ)** | **< ۰٫۵ مگابایت** | ✅ نصب از مرورگر | ✅ نصب از مرورگر | ✅ ۱۰۰٪ | ⭐ انتخاب‌شده |

یک کدبیس، هر دو پلتفرم، بدون کرش و بدون اشغال حافظه‌ی گوشی.

## امکانات

- 📅 **امروز**: تاریخ شمسی، قالب روز (کاری/خانه/پنجشنبه/جمعه)، کارت «اکنون»، تیک‌زدن کارها
  (کار تیک‌خورده از فهرست امروز محو می‌شود و نمودار پیشرفت خودکار جلو می‌رود)
- ➕ افزودن برنامه و جلسه‌ی جدید — یک‌باره یا عادت هفتگی
- 🪨⚖️🔥 سه سطح شدت روز: کف / عادی / اوج
- 📈 **روند رشد**: نمودار هفته، هیت‌مپ ماه شمسی، میانگین سال + آمار پنج ستون (عبادت، علم، بدن، خلق، نظم)
- 🎯 **حالت تمرکز**: تایمر ۲۵/۵۰/۷۰/۹۰ دقیقه + استراحت خودکار ۵/۱۵/۳۰ دقیقه
- 🎵 شش صدای محیطی که **واقعاً پخش می‌شوند** (لوفای، باران، شومینه، دریا، کافه، نویز) —
  سنتز زنده با Web Audio؛ بدون فایل صوتی و بدون حجم
- 🌙 **مرور روز**: محاسبه‌ی شب با ۵ پرسش، امتیاز ۵ ستون، سه کار فردا (فردا خودکار در «امروز» ظاهر می‌شوند)، ثبت خواب
- 🌗 حالت شب/روز (پیش‌فرض: تیره) با رنگ‌های شاد
- 🕌 اوقات شرعی محاسباتی (روش ژئوفیزیک تهران) برای ۸ شهر — کاملاً آفلاین
- 💾 پشتیبان‌گیری و بازیابی JSON — داده‌ها فقط روی دستگاه خودت

## اجرا (توسعه)

```bash
cd app
npm install
npm run dev
```

## نسخه‌ی دسکتاپ (روی سیستم خودت)

```bash
cd app
npm install
npm run desktop
```

سپس در مرورگر `http://localhost:4173` را باز کن. برای اینکه مثل یک اپ مستقل بالا بیاید:
در کروم/اج روی آیکون «نصب» در نوار آدرس بزن (**Install App**) — اپ با پنجره‌ی خودش و
آیکون در منوی استارت نصب می‌شود و بعد از آن آفلاین هم کار می‌کند.

## نصب روی اندروید

1. پوشه‌ی `dist` را (بعد از `npm run build`) روی هر هاست استاتیک یا همان شبکه‌ی خانگی سرو کن:
   `npm run desktop -- --host` و از گوشی به IP سیستم وصل شو
   (یا رایگان روی GitHub Pages / Netlify / Vercel آپلود کن).
2. صفحه را در کروم اندروید باز کن.
3. منوی کروم → **افزودن به صفحه‌ی اصلی (Add to Home Screen)**.
4. اپ با آیکون خودش نصب می‌شود، تمام‌صفحه باز می‌شود و **بدون اینترنت** کار می‌کند.

> حجم کل اپ کمتر از نیم مگابایت است؛ هیچ داده‌ای از دستگاه خارج نمی‌شود.

## ساختار کد

```
src/
  lib/        تقویم جلالی، اوقات شرعی، اعداد فارسی، ذخیره‌سازی
  data/       قالب‌های روز (برگرفته از program-config.seed.json)
  engine/     موتور تولید برنامه‌ی روز و جمع‌بندی امتیازها
  audio/      موتور سنتز صدای محیطی (Web Audio)
  pages/      چهار صفحه: امروز، روند رشد، حالت تمرکز، مرور روز
```
