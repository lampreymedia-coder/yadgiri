# BotFather بله — راه‌اندازی `@orbitionadminbot`

بازوی پدر رسمی: [@BotFather](https://ble.ir/botfather) داخل **بله** (نه تلگرام).
حسابی که بازو را ساخته باید این مراحل را بزند (فاطمه).

## اگر دستی چیزی را خراب کردید — فقط همین سه کار

توکن را عوض نکنید. `/revoke` و `/deletebot` نزنید.

1. `/setprivacy` → `@orbitionadminbot` → **Disable / غیرفعال / خاموش**  
   (اگر نوشت Enabled یعنی بازو متن گروه را نمی‌بیند.)
2. `/setjoingroups` → **Enable / مجاز**
3. `/setcommands` → همین بلوک را یک‌جا بفرستید:

```
start - شروع و فعال‌سازی گفتگوی خصوصی
help - راهنمای آرشیو و هشتگ
my - آخرین ثبت‌های من
undo - لغو ثبت با کد
resume - ادامه گفتگوی نیمه‌کاره
archive - این گروه، آرشیو یک هشتگ شود
panel - پنل مدیریت
```

بعد بازو را در گروه مشکل‌دار **اخراج** کنید، دوباره **عضو** کنید، از فهرست اعضا **ادمین** کنید. همه را مدیر نگذارید.

دو کار جداست؛ قاطی نکنید:

| کار | دستور BotFather | مشکل متن گروه را حل می‌کند؟ |
|-----|------------------|------------------------------|
| منوی `/` برای کاربر | `/setcommands` | خیر. فقط منو می‌سازد. API ما `setMyCommands` را با **501** جواب می‌دهد؛ پس منو را باید همین‌جا بگذارید. |
| دیدن **همه** پیام‌های گروه | `/setprivacy` → **Disable / غیرفعال** | **بله، اگر بله این دستور را داشته باشد.** این همان Privacy Mode تلگرام است. |

اگر `/setprivacy` در `/help` بات‌فادر نبود، این مسیر به‌تنهایی مشکل «تست ربات» را حل نمی‌کند.

توکن را عوض نکنید (`/revoke` نزنید). بازو را حذف نکنید (`/deletebot` نزنید).

## گام ۰ — فهرست واقعی دستورهای بات‌فادر

در بله:

1. جستجو: `BotFather` — بازوی رسمی با تیک.
2. باز کنید و بفرستید:

```
/start
```

بعد:

```
/help
```

هر خطی که بات‌فادر جواب داد را نگه دارید. بعد به ترتیب زیر بروید. اگر دستوری در فهرست نبود، از آن رد شوید و به گام بعد بروید.

احتمالاً می‌بینید (بله از تلگرام کپی کرده؛ همه ممکن است نباشند):

- `/mybots`
- `/setname`
- `/setdescription`
- `/setabouttext`
- `/setuserpic`
- `/setcommands`
- `/setjoingroups`
- `/setprivacy`
- `/token` — فقط ببینید؛ کپی نکنید توی چت عمومی
- `/revoke` — **نزنید**

## گام ۱ — حریم خصوصی گروه (مهم‌ترین)

این همان چیزی است که در تلگرام متن عادی گروه را به بازو می‌دهد.

```
/setprivacy
```

1. اگر لیست بازوها آمد، `@orbitionadminbot` را انتخاب کنید.
2. متن وضعیت را بخوانید.

معنی وضعیت (وارونه است، دقیق بخوانید):

| بات‌فادر نوشت | معنی | کار شما |
|----------------|------|---------|
| Enabled / فعال / روشن | بازو **فقط** `/دستور` و منشن را می‌بیند | باید **خاموش** شود |
| Disabled / غیرفعال / خاموش | بازو **همه** پیام‌های گروه را می‌بیند | همین را می‌خواهیم؛ دیگر عوض نکنید |

دکمه یا کلمه‌ای که باید بزنید:

- انگلیسی: `Disable`
- فارسی احتمالی: `غیرفعال` یا `خاموش` یا `خاموش کردن حالت حریم خصوصی`

هدف نهایی یک جمله است: **بازو همه پیام‌های گروه را دریافت کند.**

مسیر جایگزین اگر `/setprivacy` نبود:

```
/mybots
```

→ `@orbitionadminbot` → تنظیمات بازو / Bot Settings → Group Privacy / حریم خصوصی گروه → Turn off / خاموش.

اگر هیچ‌کدام نبود: همان را به توسعه‌دهنده بگویید؛ مشکل از پلتفرم است نه از منوی دستور.

### بعد از تغییر حریم خصوصی — الزامی

در تلگرام (و معمولاً بله) تنظیم **روی گروه‌هایی که از قبل عضو است اعمال نمی‌شود** مگر بازو را یک‌بار بیرون کنید و دوباره اضافه کنید.

برای **تست ربات** و **سنجش ربات**:

1. بازو را از گروه حذف کنید (اخراج، نه بلاک).
2. دوباره **عضو** کنید، بعد از فهرست اعضا **ادمین** کنید.
3. چند نفر را از ادمینی درآورید تا تقریباً همه مدیر نباشند.
4. یک نقطه بفرستید: `.`

گروه **cyber Economy** که الان کار می‌کند را آخر دست بزنید؛ اول گروه‌های خراب را آزمایش کنید.

```
/setjoingroups
```

`@orbitionadminbot` را انتخاب کنید. وضعیت باید **Enable / مجاز / روشن** باشد تا بتوان بازو را به گروه اضافه کرد. اگر Disable بود Enable کنید.

## گام ۳ — منوی دستورها (کپی کامل)

```
/setcommands
```

`@orbitionadminbot` را انتخاب کنید.

اگر پرسید برای همه / گروه / خصوصی: اول **Default / پیش‌فرض / همه کاربران** را بگذارید.

بعد **دقیقاً** این بلوک را در یک پیام بفرستید (بدون `/` اول نام دستور، یک فاصله، خط تیره، فاصله، توضیح):

```
start - شروع و فعال‌سازی گفتگوی خصوصی
help - راهنمای آرشیو و هشتگ
my - آخرین ثبت‌های من
undo - لغو ثبت با کد
resume - ادامه گفتگوی نیمه‌کاره
archive - این گروه، آرشیو یک هشتگ شود
panel - پنل مدیریت
```

اگر بات‌فادر خطا داد (طول توضیح، کاراکتر فارسی، یا تعداد خط):

نسخهٔ کوتاه لاتین:

```
start - Start private chat
help - How the archive works
my - My recent items
undo - Undo by code
resume - Resume unfinished tagging
archive - Bind this group as a hashtag archive
panel - Admin panel
```

دستورهای `stats` `groups` `health` `search` `export` در کد هستند ولی منوی عمومی را شلوغ نکنید؛ مدیر همان‌ها را دستی می‌زند.

## گام ۴ — معرفی بازو (اختیاری ولی حرفه‌ای)

### نام نمایشی

```
/setname
```

پیشنهاد (اگر هنوز «اربیشن» را می‌خواهید نگه دارید عوض نکنید):

```
آرشیو اربیشن
```

### توضیح صفحهٔ شروع (تا حدود ۵۱۲ نویسه)

```
/setdescription
```

بعد این متن:

```
ربات آرشیو اربیشن

محتوای گروه رصد را با هشتگ در گروه آرشیو خصوصی ذخیره می‌کند.

۱) بازو را به گروه اضافه کنید و از فهرست اعضا ادمین کنید.
۲) در خصوصی بازو /start را بزنید.
۳) متن، فایل، صوت یا فوروارد را در گروه ربات بفرستید؛ سؤال هشتگ در خصوصی می‌آید.
۴) برای هر هشتگ یک گروه آرشیو جدا بسازید و داخلش بنویسید: آرشیو

هشتگ‌ها: یادگیری، شبکه و منبع، محتوایی، سند.
استیکر و گیف ذخیره نمی‌شوند.
```

### درباره (کوتاه، پروفایل)

```
/setabouttext
```

```
آرشیو گروهی با هشتگ؛ سؤال در خصوصی، محتوا در گروه رصد می‌ماند.
```

عکس پروفایل اگر دارید:

```
/setuserpic
```

و یک تصویر مربع بفرستید.

## گام ۵ — تست بعد از بات‌فادر

در خصوصی `@orbitionadminbot` یک `/` بزنید. باید منوی گام ۳ دیده شود. `/start` و `/help` باید جواب بدهند.

در گروه مشکل‌دار (بعد از اخراج و افزودن دوباره):

1. بدون منشن یک `.` بفرستید.
2. اگر ویزارد خصوصی آمد: حریم خصوصی اثر کرده.
3. اگر نیامد، `@orbitionadminbot .` بفرستید. اگر فقط منشن کار کرد، بله هنوز Privacy Mode را روی آن گروه اعمال می‌کند.

گروه «سنجش ربات» اگر سؤال رصد/آرشیو نیامد، داخل گروه بفرستید:

```
/start
```

یا:

```
@orbitionadminbot
```

## چیزهایی که نباید بزنید

- `/revoke` — توکن فعلی می‌میرد و ربات خاموش می‌شود تا `.env` عوض شود.
- `/deletebot`
- `/setinline` لازم نیست؛ این بازو اینلاین نیست.
- وب‌هوک در بات‌فادر اگر چیزی پرسید خالی بماند؛ اجرا پولینگ است.
